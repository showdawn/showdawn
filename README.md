## Technical work

### [Inventory event reconciliation lab](https://github.com/showdawn/inventory-event-reconciliation-lab)

A runnable Python and SQLite example of duplicate deliveries, delayed events and snapshot recovery. Compare three inventory consumers against the same synthetic trace, then inspect the eleven tests and documented limits.

[![Tests](https://github.com/showdawn/inventory-event-reconciliation-lab/actions/workflows/tests.yml/badge.svg)](https://github.com/showdawn/inventory-event-reconciliation-lab/actions/workflows/tests.yml)
[![Python](https://img.shields.io/badge/Python-3.9%2B-3776AB)](https://github.com/showdawn/inventory-event-reconciliation-lab)
[![SQLite](https://img.shields.io/badge/Storage-SQLite-003B57)](https://github.com/showdawn/inventory-event-reconciliation-lab)

This is an educational companion to the book. Results describe the synthetic example. The repository documents AI assistance and the assumptions that limit production use.
